# FerreteriaSV ERP - Ejercicios WPF

Proyecto desarrollado en WPF (.NET 10) como parte de la práctica de desarrollo de aplicaciones de escritorio.

## Ejercicios incluidos

1. Login de empleados
2. Registro de clientes (DUI/NIT)
3. Punto de venta
4. Consulta y filtros de inventario

## Requisitos

* Windows 10 o superior
* Visual Studio 2022
* SDK de .NET 10 instalado

## Instrucciones para compilar

1. Clonar o descargar el repositorio.
2. Abrir la solución (`FerreteriaSV.sln`) en Visual Studio 2022.
3. Esperar a que Visual Studio restaure las dependencias automáticamente.
4. Seleccionar el proyecto **FerreteriaSV** como proyecto de inicio.
5. Presionar **F5** o hacer clic en **Iniciar depuración**.

## Navegación

Al iniciar la aplicación se muestra un menú principal desde donde se puede acceder a cada uno de los ejercicios:

* Ejercicio 01: Login de empleados
* Ejercicio 02: Registro de clientes
* Ejercicio 03: Punto de venta
* Ejercicio 04: Inventario

## Tecnologías utilizadas

* C#
* WPF
* .NET 10
* XAML

# Calculadora de Planilla - WPF C#

Aplicación desarrollada en WPF (.NET Framework) para el cálculo de planilla mensual en El Salvador, incluyendo descuentos de ISSS, AFP y Renta.

## Requisitos

* Visual Studio 2022 o superior.
* .NET Framework 4.8 (o la versión utilizada en el proyecto).
* Sistema operativo Windows.

## Instrucciones para compilar

1. Clonar o descargar el repositorio.
2. Abrir el archivo de solución (`.sln`) en Visual Studio.
3. Esperar a que Visual Studio restaure las dependencias necesarias.
4. Seleccionar la configuración **Debug** o **Release**.
5. Presionar **Ctrl + Shift + B** o ir a **Build > Build Solution** para compilar el proyecto.
6. Ejecutar la aplicación presionando **F5** o seleccionando **Start Debugging**.

## Funcionalidades

* Cálculo automático de ISSS (3% con tope de $1,000).
* Cálculo automático de AFP (7.25%).
* Cálculo de Renta según tramos establecidos.
* Cálculo de salario líquido.
* Validación de datos de entrada.
* Visualización de descuentos mediante DataGrid.
* Simulación de impresión de boleta.
